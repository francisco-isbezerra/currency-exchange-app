# Hermes — Currency Exchange App

> Projeto 01 — Disciplina de Desenvolvimento Web

A SPA for real-time currency conversion and historical exchange rate analysis.

## Tech Stack
- **React + Vite** (JSX)
- **CSS Modules**
- **Recharts** — charts
- **Lucide React** — icons
- **date-fns** — date manipulation
- **PapaParse** — CSV export
- **Frankfurter API** — free currency data (no API key needed)

## Getting Started

```bash
npm install
npm run dev
```

## Features
- 💱 Live currency converter with swap
- 📈 Historical rate charts (7d to 10y)
- 📊 Data table with filter, sort, pagination
- 📥 Export to CSV

## Git Workflow
- `main` — stable production branch
- `dev` — integration branch
- `feat/*` — feature branches
